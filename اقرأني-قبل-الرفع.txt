محلل نتائج نافس — الإصدار ٧٫١ AI الآمن

هذه نسخة GitHub Pages محدثة ومربوطة مسبقًا بالخادم الآمن:
https://nafis-ai-reader.harthy298.workers.dev/analyze

أهم التعديلات:
- فصل العام الدراسي (مثل ١٤٤٧هـ) عن سنة القياس (مثل ٢٠٢٦).
- إظهار الرقم الوزاري كاملًا عند وجوده في الملف.
- فصل إدارة التعليم عن المنطقة وعدم اختصار أحدهما إلى الآخر.
- إظهار مقدار التغير العام المرتبط بالمؤشر العام.
- تصنيف المجالات إلى: علاجي / تحسين / محافظة على القوة.
- أوراق العمل تُنشأ فقط للمجالات العلاجية أو مجالات التحسين.
- لا يُفترض أن نوع المدرسة حكومي إذا لم يظهر في المصدر.
- لا يوجد صف افتراضي أو بيانات مدرسة ثابتة في مسار القراءة.
- عند رفع ملف جديد تُمسح حالة الملف السابق قبل بدء القراءة.
- أزيلت أزرار البيانات التجريبية من الواجهة العامة.
- لا يوجد حد مخصص لعدد مرات الاستخدام داخل كود التطبيق في هذا الإصدار؛ الاستهلاك يعتمد على رصيد OpenAI API وحدود الخدمة.

طريقة التحديث:
1) حدّثي Cloudflare Worker أولًا بكود V7.1 ثم انشريه.
2) لا تحذفي OPENAI_API_KEY ولا تنشئي مفتاحًا جديدًا؛ الـSecret الحالي يبقى كما هو.
3) بعد ذلك ارفعي محتويات حزمة GitHub V7.1 إلى مستودع Nafis-Analysis مع استبدال الملفات القديمة.
4) انتظري GitHub Pages ثم افتحي الموقع واضغطي Ctrl+F5 مرة واحدة.
5) اختبري ملفًا واحدًا وقارني القيم بالمصدر قبل النشر العام.

ملاحظة: القارئ مخصص لبطاقات نافس PDF/PNG/JPG ضمن الصفوف المدعومة: الثالث الابتدائي، السادس الابتدائي، والثالث المتوسط.
