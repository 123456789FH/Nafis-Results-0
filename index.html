الإصدار ٧٫١ AI الآمن — لا يُكشف مفتاح API للمستفيد، ولا توجد قاعدة بيانات للمدارس في الحزمة. تُرسل البطاقة مؤقتًا إلى خدمة AI للقراءة عند تفعيلها، ثم يبقى التحليل والتصدير محليين.

الخصوصية والأمان

ما الذي يحدث للملف في الإصدار ٧؟ تُنشأ المعاينة في جهازك. وعند تفعيل قارئ AI تُرسل نسخة مؤقتة من محتوى البطاقة عبر اتصال HTTPS إلى Cloudflare Worker ثم إلى OpenAI API للقراءة المنظمة.

  • مفتاح OpenAI API محفوظ كسر في الخادم الوسيط ولا يوجد داخل GitHub أو JavaScript في المتصفح.
  • لا يرسل التطبيق اسم الملف الأصلي؛ يستخدم اسمًا عامًا مثل nafis-card.pdf.
  • الخادم المرفق لا ينشئ قاعدة بيانات ولا يكتب محتوى البطاقة إلى سجلات التطبيق، ويرسل طلب OpenAI مع store:false.
  • الناتج من AI مقيد بمخطط JSON ثابت، ثم يمر باختبارات اتساق حسابية، وتظل المراجعة البشرية إلزامية.
  • عند عدم التأكد من رقم يُطلب من النموذج إرجاع قيمة فارغة بدل التخمين.
  • يمكن استخدام الإدخال اليدوي إذا لم ترغبي بإرسال البطاقة إلى خدمة AI.

مهم: هذه أداة تحليل مدرسية مساندة. راجعي سياسة الجهة التي تتبعين لها قبل إرسال وثائق تحتوي بيانات حساسة إلى أي خدمة سحابية.
